    3.1. Exemplo 01: a estrutura de um aplicativo Flutter

    3.1.1. O projeto

    Um projeto [Flutter] é criado com o comando [flutter create]:

    1
    flutter create --org fr.stahe --platforms=android,web,windows my_application
    • [--org fr.stahe]: o prefixo do ID do aplicativo, invertido como um nome de domínio. O aplicativo [Android] se chamará [fr.stahe.my_application]; dois aplicativos instalados no mesmo celular devem ter IDs diferentes;
    • [--platforms=...]: as plataformas de destino. Para cada uma delas, o [flutter create] cria uma pasta ([android/], [web/], [windows/] e também [ios/], [macos/], [linux/] se solicitadas): um pequeno projeto específico da plataforma que apenas inicia o motor do [Flutter] e carrega o aplicativo nele. Raramente fazemos alterações nele (o nome do aplicativo, o ícone e as permissões);
    • [my_application]: o nome do projeto, que também é o nome do pacote [Dart]: letras minúsculas, números e sublinhados.

    O comando gera um aplicativo completo e pronto para executar (um contador). O projeto de exemplo foi criado da mesma forma e, em seguida, sua pasta [lib/] foi preenchida manualmente para reunir vinte e cinco aplicativos em um único projeto: assim, eles compartilham os mesmos pacotes, que são baixados uma única vez.

Ele é executado automaticamente pelo [flutter run] quando o [pubspec.yaml] foi alterado; o [VS Code] também o executa assim que esse arquivo é salvo. Para adicionar um pacote, em vez de editar o arquivo manualmente, você pode digitar [flutter pub add go_router]: o comando adiciona a linha com a versão mais recente do pacote.

    // =========================================================================
// lib/ex01_first_application/main.dart - um primeiro aplicativo
// -------------------------------------------------------------------------
// Tudo, em um aplicativo Flutter, é um WIDGET: um objeto que descreve
// um pedaço da tela (um texto, um botão, uma margem, uma coluna...).
// Os widgets são aninhados uns nos outros e formam uma ÁRVORE.
// Um widget tem um método build(), que RETORNA os widgets que
// o compõem. O Flutter chama build() para produzir a tela; ele
// O CHAMA DE NOVO a cada vez que o estado do widget muda (setState), e
// atualiza a tela com o novo resultado.
// =========================================================================

import 'package:flutter/material.dart';

// dados "comuns", fora dos widgets: nunca mudam
const title = 'Welcome to Flutter';
const languages = ['Dart', 'Flutter', 'Material Design'];

// "12:05:09": a hora atual, em dois dígitos
String currentTime() {
  final d = DateTime.now();
  String twoDigits(int n) => n.toString().padLeft(2, '0');
  return '${twoDigits(d.hour)}:${twoDigits(d.minute)}:${twoDigits(d.second)}';
}

// o ponto de entrada de todo programa Dart
void main() {
  // runApp: o Flutter assume a tela e exibe nela o widget RAIZ
  runApp(const Application());
}

// o widget raiz: ele configura o aplicativo (título, tema, primeira tela).
// StatelessWidget: um widget SEM estado, inteiramente descrito por seus parâmetros
class Application extends StatelessWidget {
  const Application({super.key});

  @override
  Widget build(BuildContext context) {
    // MaterialApp: um aplicativo com as cores e o comportamento do
    // Material Design, a linguagem visual do Google
    return MaterialApp(
      title: 'Example 01',
      // sem o banner "DEBUG" no canto da tela
      debugShowCheckedModeBanner: false,
      // as cores de todo o aplicativo, derivadas de uma cor base
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const HomePage(),
    );
  }
}

// um widget COM estado: ele vem em duas partes, o widget propriamente dito (que nunca
// muda) e um objeto State (que guarda os dados que mudam)
class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

// o "_": esta classe é PRIVADA, invisível fora deste arquivo
class _HomePageState extends State<HomePage> {
  // o ESTADO: campos simples do objeto State
  int _counter = 0;
  String _time = currentTime();

  // a função chamada pelo botão
  void _increment() {
    // setState: o estado é modificado DENTRO da função passada a setState;
    // o Flutter então chama build() de novo para atualizar a tela. Nunca
    // modificamos a tela diretamente
    setState(() {
      _counter++;
      _time = currentTime();
    });
  }

  @override
  Widget build(BuildContext context) {
    // Scaffold: a estrutura de uma tela Material (barra superior, corpo...)
    return Scaffold(
      appBar: AppBar(title: const Text('Example 01 - a first application')),
      // Padding: uma margem ao redor do seu filho
      body: Padding(
        padding: const EdgeInsets.all(16),
        // Column: filhos dispostos um abaixo do outro
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(title, style: Theme.of(context).textTheme.headlineSmall),
            const SizedBox(height: 12),
            const Text(
              'This screen is produced by Flutter, from the main function '
              'and the Application and HomePage widgets.',
            ),
            const SizedBox(height: 8),
            // ${expression} insere o valor de uma expressão em uma string
            Text('It is written in ${languages.join(', ')} (${languages.length} languages).'),
            const SizedBox(height: 16),
            // onPressed: a função a chamar quando o botão é pressionado (veja o exemplo 04)
            FilledButton(onPressed: _increment, child: const Text('Click me')),
            const SizedBox(height: 16),
            Text(
              'You clicked $_counter times (last click: $_time).',
              style: const TextStyle(fontWeight: FontWeight.bold, color: Color(0xFF087EA4)),
            ),
          ],
        ),
      ),
    );
  }
}

    Vamos começar pelo fim: o programa.

    • Linha 13: a biblioteca [Material] do [Flutter]: todos os widgets do [Material Design], a linguagem visual do [Google] (botões, campos de entrada, barras, janelas etc.). Ela importa o restante do próprio [Flutter];
    • linhas 16–17: dois valores de dados comuns, declarados fora dos widgets: eles nunca mudam. [const]: uma constante conhecida em tempo de compilação;
    • linhas 20–23: uma função comum que retorna a hora atual no formato “12:05:09”. Ela contém uma pequena função própria, [twoDigits], escrita em uma única linha com [=>];
    • linhas 27–29: a função [main], chamada na inicialização. [runApp] inicia o [Flutter]: ele assume o controle da tela e exibe o widget que lhe é fornecido — a raiz do aplicativo.

    O widget raiz, [Application]:

    • Linha 34: um widget é uma classe. Esta classe herda de [StatelessWidget], um widget sem estado: o que ele exibe depende exclusivamente de seus parâmetros e nunca muda por conta própria;
    • Linha 29: seu construtor. [{super.key}]: um parâmetro nomeado opcional repassado à classe pai. Todo widget tem um: a “chave” que o identifica (veja o Exemplo 04). O construtor é [const]: [Application()] pode ser uma constante que o [Flutter] nunca precisa reconstruir;
    • Linhas 38–47: o método [build], o núcleo de um widget. Ele retorna os widgets que o compõem. [@override]: ele sobrescreve o método [build] da classe pai. O parâmetro [context] é a posição do widget na árvore de widgets: ele serve para recuperar o que seus ancestrais fornecem (o tema, por exemplo, linha 90);
    • linhas 41–47: [MaterialApp] é o widget que transforma uma árvore de widgets em um aplicativo [Material]: um título ([title], o nome do aplicativo na lista de aplicativos recentes do celular ou na aba do navegador), um tema ([theme]) e uma tela inicial ([home]). [debugShowCheckedModeBanner: false] remove o banner “DEBUG” que um aplicativo em desenvolvimento exibe em um canto. [ThemeData(colorSchemeSeed: Colors.indigo)]: todas as cores do aplicativo (botões, barras, campos etc.) derivam de uma única cor base, de acordo com as regras do [Material Design] 3.

    A primeira tela, [HomePage], tem dados que mudam: é um widget com estado.

    • Linhas 54–58: um [StatefulWidget] é composto de duas partes. O widget em si, como qualquer widget, nunca muda (seus campos seriam [final]); sua única tarefa é criar, por meio de [createState], um objeto [State], que por sua vez contém os dados que mudam. O [Flutter] cria esse objeto uma só vez e o mantém enquanto o widget permanecer no mesmo lugar da árvore;
    • linha 62: o objeto [State]. Seu nome começa com um sublinhado: em [Dart], tudo que começa com [_] é privado e invisível fora do arquivo;
    • linhas 64–65: o estado: campos simples do objeto [State];
    • linhas 68–75: o método chamado pelo botão. Ele não afeta a tela: ele altera o estado dentro da função passada a [setState]. [setState] executa essa função e, em seguida, notifica o [Flutter] de que o estado mudou: o [Flutter] chamará [build], comparará a nova árvore de widgets com a antiga e redesenhará o que mudou;
    • linhas 79–105: o [build] da tela:
      • [Scaffold] (“andaime”) é a estrutura de uma tela [Material]: uma barra superior ([appBar]), um corpo ([body]) e, se solicitados, uma barra inferior, um botão flutuante e um menu lateral;
      • [AppBar]: a barra superior; seu título é um widget ([Text]), como quase tudo no [Flutter];
      • [Padding]: uma margem ao redor de seu único filho, [child]. [EdgeInsets.all(16)]: 16 pontos de cada lado (um “ponto” lógico, independente da densidade da tela: aproximadamente 2,6 pixels no celular mostrado nas capturas de tela);
      • [Column]: seus filhos, [children], dispostos um abaixo do outro. [crossAxisAlignment: CrossAxisAlignment.start]: alinhados à esquerda (o eixo “transversal” de uma coluna é o eixo horizontal);
      • [Text]: texto. Seu estilo pode ser derivado do tema: [Theme.of(context).textTheme.headlineSmall] é o estilo para “títulos pequenos”;
      • [SizedBox]: uma caixa vazia com uma altura especificada — um espaço entre dois widgets;
      • linha 98: [${expression}] insere o valor de uma expressão em uma string; [$_counter] basta para uma variável simples (linha 104);
      • linha 101: um botão. [onPressed] recebe a função a ser chamada quando o botão é pressionado. Especificamos a própria função, sem parênteses: [onPressed: _increment()] a chamaria imediatamente, durante a construção da tela;
      • linhas 104–105: texto que depende do estado. Quando o estado muda, [build] é chamado e esse texto muda.

    Duas observações sobre [Dart]:

    • quase todos os argumentos de widgets são parâmetros nomeados ([title: ...], [child: ...]): a árvore de widgets se lê como uma descrição, e a ordem dos argumentos não importa. Um parâmetro nomeado é opcional, a menos que seja declarado como [required];
    • a palavra-chave [const] antes de um widget ([const SizedBox(height: 12)]) o cria de uma vez por todas em tempo de compilação. O [Flutter] passa então a saber que ele nunca muda e não perde tempo comparando-o. O analisador sinaliza qualquer [const] omitido; o [VS Code] sabe adicioná-los sozinho.

// Uma pequena calculadora de preços com IVA:
//   - o ESTADO: os campos do objeto State; alterá-los DENTRO de setState()

//     "getter" (ou uma variável local de build), recalculado a cada chamada
//     de build(). Está sempre atualizado, sem nada para sincronizar;
//   - um dado que depende dos valores SUCESSIVOS do estado (o histórico
//     dos totais) é atualizado onde o estado muda: em setState;
//   - o título do aplicativo (aba do navegador, lista de aplicativos

import 'package:intl/intl.dart';

// um formatador de valores em euros, à moda americana (€1,234.50), veja o exemplo 09
final euros = NumberFormat.currency(locale: 'en_US', symbol: '€');

  runApp(

class CalculatorPage extends StatefulWidget {
  const CalculatorPage({super.key});

  @override
  State<CalculatorPage> createState() => _CalculatorPageState();
}

class _CalculatorPageState extends State<CalculatorPage> {
  // o estado
  String _label = 'Pen';
  double _priceExclVat = 2.5;
  int _quantity = 1;
  double _vatRate = 20; // em %
  // o histórico das últimas 5 alterações do total com IVA
  final List<String> _history = [];

  // um controller dá acesso ao TEXTO de um campo de entrada: precisamos de um
  // aqui para devolvê-lo ao valor inicial (Reset). O exemplo 05
  // os estuda em detalhe
  final _labelField = TextEditingController(text: 'Pen');
  final _priceField = TextEditingController(text: '2.5');

  // valores CALCULADOS: getters, recalculados a cada leitura
  double get _totalExclVat => _quantity * _priceExclVat;
  double get _vatAmount => _totalExclVat * _vatRate / 100;
  double get _totalInclVat => _totalExclVat + _vatAmount;

  // TODAS as alterações do estado passam por este método: ele anota o
  // total com IVA antes da alteração, aplica a alteração e completa
  // o histórico se o total mudou
  void _change(void Function() change) {
    final oldTotal = _totalInclVat;
    setState(() {
      change();
      if (_totalInclVat != oldTotal) {
        _history.insert(0, '${euros.format(oldTotal)} -> ${euros.format(_totalInclVat)}');
        if (_history.length > 5) {
          _history.removeLast();
        }
      }
    });
  }

  // trocar o item redefine a quantidade para 1: fazemos isso onde sabemos
  // POR QUE o estado muda
  void _changeLabel(String newValue) {
    _change(() {
      _label = newValue;
      _quantity = 1;
    });
  }

  void _reset() {
    _change(() {
      _label = 'Pen';
      _priceExclVat = 2.5;
      _quantity = 1;
      _vatRate = 20;
    });
    _labelField.text = 'Pen';
    _priceField.text = '2.5';
  }

  // o objeto State desaparece (saímos da tela): os controllers são liberados
  @override
  void dispose() {
    _labelField.dispose();
    _priceField.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final totalStyle = Theme.of(context).textTheme.titleMedium!.copyWith(fontWeight: FontWeight.bold);

    // Title: o título do aplicativo ACOMPANHA o estado, como todo o resto
    return Title(
      title: 'Incl. VAT: ${euros.format(_totalInclVat)}',
      color: Colors.indigo,
      child: Scaffold(
        appBar: AppBar(title: const Text('Example 02 - the state')),
        // ListView: uma coluna que rola se ultrapassar a altura da tela
        body: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            Card(
              child: Padding(
                padding: const EdgeInsets.all(16),
                child: Column(
                  children: [
                    // onChanged: chamado a cada tecla digitada, com o novo texto
                    TextField(
                      controller: _labelField,
                      decoration: const InputDecoration(labelText: 'Item'),
                      onChanged: _changeLabel,
                    ),
                    TextField(
                      controller: _priceField,
                      decoration: const InputDecoration(labelText: 'Unit price excl. VAT'),
                      // o teclado numérico do celular, com o ponto decimal
                      keyboardType: const TextInputType.numberWithOptions(decimal: true),
                      // tryParse: null se o texto não for um número; a vírgula também é aceita
                      onChanged: (text) => _change(() => _priceExclVat = double.tryParse(text.replaceAll(',', '.')) ?? 0),
                    ),
                    const SizedBox(height: 12),
                    Row(
                      children: [
                        const Expanded(child: Text('Quantity (back to 1 if the item changes)')),
                        IconButton(
                          icon: const Icon(Icons.remove),
                          // null: o botão fica desabilitado
                          onPressed: _quantity > 0 ? () => _change(() => _quantity--) : null,
                        ),
                        Text('$_quantity', style: totalStyle),
                        IconButton(icon: const Icon(Icons.add), onPressed: () => _change(() => _quantity++)),
                      ],
                    ),
                    const SizedBox(height: 8),
                    // botões dos quais apenas UM é selecionado: a alíquota do IVA
                    SegmentedButton<double>(
                      segments: const [
                        ButtonSegment(value: 5.5, label: Text('5.5%')),
                        ButtonSegment(value: 10, label: Text('10%')),
                        ButtonSegment(value: 20, label: Text('20%')),
                      ],
                      selected: {_vatRate},
                      onSelectionChanged: (choice) => _change(() => _vatRate = choice.first),
                    ),
                    const SizedBox(height: 12),
                    OutlinedButton(onPressed: _reset, child: const Text('Reset')),
                  ],
                ),
              ),
            ),
            Card(
              child: Padding(
                padding: const EdgeInsets.all(16),
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text('$_quantity x $_label', style: Theme.of(context).textTheme.titleLarge),
                    const Divider(),
                    _line('Total excl. VAT', euros.format(_totalExclVat)),
                    _line('VAT ($_vatRate%)', euros.format(_vatAmount)),
                    _line('Total incl. VAT', euros.format(_totalInclVat), style: totalStyle),
                  ],
                ),
              ),
            ),
            Card(
              child: Padding(
                padding: const EdgeInsets.all(16),
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text('History of the total incl. VAT', style: Theme.of(context).textTheme.titleSmall),
                    // uma linha de texto por elemento do histórico (veja o exemplo 03)
                    for (final line in _history) Text('• $line'),
                  ],
                ),
              ),
            ),
          ],
        ),
      ),
    );
  }

  // uma linha "rótulo ....... valor": um método que produz widgets
  Widget _line(String label, String amount, {TextStyle? style}) {
    return Padding(
      padding: const EdgeInsets.symmetric(vertical: 4),
      child: Row(
        children: [
          Expanded(child: Text(label, style: style)),
          Text(amount, style: style),
        ],
      ),
    );
  }

// lib/ex03_widgets/main.dart - escrevendo uma árvore de widgets
// -------------------------------------------------------------------------
// O Flutter não tem linguagem de template (nem HTML, nem JSX): as
// telas são escritas em Dart, com construtores de widgets aninhados.

//   - if (condição) widget          : um filho que só EXISTE se a
//                                      condição for verdadeira ("collection if");
//   - if (c) widgetA else widgetB    : um OU o outro;
//   - condição ? widgetA : widgetB  : o mesmo, em uma expressão;
//   - for (final x in lista) widget   : um filho por elemento da lista
//                                      ("collection for");
//   - ...outraLista                   : os elementos de outra lista,
//                                      inseridos neste ponto ("spread");
//   - switch (valor) { padrão => ... } : um valor entre vários.
// E tudo o que vem antes do return de build() é código comum.

import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';

// uma "enumeração": os únicos valores possíveis de uma especialidade
enum Specialty { generalPractitioner, pediatrician, cardiologist }

// uma classe de dados: seus campos são final, um objeto Doctor nunca
// muda. O construtor "const" permite criar constantes dela
class Doctor {
  final int id;
  final String title;
  final String firstName;
  final String lastName;
  final Specialty specialty;
  final bool available;

  const Doctor(this.id, this.title, this.firstName, this.lastName, this.specialty, this.available);
}

const doctors = [
  Doctor(1, 'Mme', 'Marie', 'PELISSIER', Specialty.generalPractitioner, true),
  Doctor(2, 'Mr', 'Paul', 'TATOU', Specialty.pediatrician, false),
  Doctor(3, 'Melle', 'Sophie', 'DUPONT', Specialty.cardiologist, true),
];

// "um valor entre vários, dependendo de um valor": uma EXPRESSÃO switch.
// O compilador verifica se todos os casos da enumeração são tratados
String label(Specialty s) => switch (s) {
  Specialty.generalPractitioner => 'general practitioner',
  Specialty.pediatrician => 'pediatrician',
  Specialty.cardiologist => 'cardiologist',
};

Icon icon(Specialty s) => switch (s) {
  Specialty.pediatrician => const Icon(Icons.child_care, color: Colors.orange),
  Specialty.cardiologist => const Icon(Icons.favorite, color: Colors.red),
  _ => const Icon(Icons.medical_services, color: Colors.teal), // "_": todos os outros casos
};

  bool _showHelp = true;

    // a lista exibida: uma variável comum, recalculada a cada build()
    final text = _filter.trim().toLowerCase();
    final displayed = doctors
        .where(
          (m) =>
              (!_onlyAvailable || m.available) &&
              '${m.firstName} ${m.lastName} ${label(m.specialty)}'.toLowerCase().contains(text),
        )
        .toList();

    // "um dos três blocos": é calculado ANTES do return, com ifs
    final Widget content;
    if (doctors.isEmpty) {
      content = const Text('No doctor.');
    } else if (displayed.isEmpty) {
      content = Text('No doctor matches "$_filter".', style: const TextStyle(color: Colors.deepOrange));
    } else {
      content = Column(
        children: [
          // um filho por médico: "collection for", com sua posição (indexada)
          for (final (i, m) in displayed.indexed)
            // Opacity: os médicos indisponíveis ficam esmaecidos
            Opacity(
              opacity: m.available ? 1 : 0.5,

                title: Text('${m.title} ${m.firstName} ${m.lastName}'),
                // Wrap: como uma Row, mas que quebra para a linha seguinte quando falta espaço
                subtitle: Wrap(
                  spacing: 6,
                  crossAxisAlignment: WrapCrossAlignment.center,
                  children: [icon(m.specialty), Text(label(m.specialty))],
                ),
                trailing: Chip(
                  label: Text(m.available ? 'available' : 'unavailable'),
                  // uma cor escolhida por uma expressão condicional
                  backgroundColor: m.available ? Colors.green.shade100 : Colors.grey.shade300,
                ),
              ),
            ),
        ],
      );
    }

    return Scaffold(
      appBar: AppBar(
        // uma imagem SVG distribuída com o aplicativo (pasta assets/, veja pubspec.yaml)
        leading: Padding(padding: const EdgeInsets.all(12), child: SvgPicture.asset('assets/doctor.svg')),
        title: const Text('Example 03 - the widgets'),

        padding: const EdgeInsets.all(16),
        children: [
          TextField(
            decoration: const InputDecoration(hintText: 'search...', prefixIcon: Icon(Icons.search)),
            onChanged: (value) => setState(() => _filter = value),
          ),
          // SwitchListTile: um interruptor, com seu rótulo
          SwitchListTile(
            title: const Text('available only'),
            value: _onlyAvailable,
            onChanged: (value) => setState(() => _onlyAvailable = value),
          ),
          Align(
            alignment: Alignment.centerLeft,
            child: TextButton(
              onPressed: () => setState(() => _showHelp = !_showHelp),
              child: Text(_showHelp ? 'Hide help' : 'Show help'),
            ),
          ),
          // "collection if": este widget só EXISTE se _showHelp for true
          if (_showHelp)

              color: Colors.lightBlue.shade50,

              ),
            ),
          content,
          const SizedBox(height: 12),

            style: TextStyle(fontSize: 12 + displayed.length * 2.0),
          ),
        ],
      ),
    );

// lib/ex04_events/main.dart - reagindo às ações do usuário
// -------------------------------------------------------------------------
// Um widget interativo recebe como parâmetros as FUNÇÕES a chamar quando
// algo acontece ("callbacks"):
//   - onPressed: f                  : f é chamada em um toque (botões);
//   - onPressed: () => remove(t)    : uma função anônima, para passar seus
//                                     próprios argumentos;
//   - onChanged, onSubmitted...     : a função recebe um dado (o
//                                     texto, a caixa marcada...);
//   - GestureDetector               : adiciona gestos (toque, toque longo,
//                                     toque duplo, arrastar...) a
//                                     QUALQUER widget;
//   - Dismissible                   : deslizar uma linha para removê-la,
//                                     o gesto típico de um celular.
// Para agir sobre um campo de entrada a partir do código (ler ou limpar seu
// texto, dar-lhe o foco), associamos a ele um CONTROLLER e um FocusNode.
// =========================================================================

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

class Task {
  final int id;
  final String label;
  bool done;

  Task(this.id, this.label, {this.done = false});
}

void main() {
  runApp(
    MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const TasksPage(),
    ),
  );
}

class TasksPage extends StatefulWidget {
  const TasksPage({super.key});

  @override
  State<TasksPage> createState() => _TasksPageState();
}

class _TasksPageState extends State<TasksPage> {
  final List<Task> _tasks = [
    Task(1, 'Install Flutter', done: true),
    Task(2, 'Read the chapter on events'),
  ];
  final List<String> _log = [];
  // o controller do campo: seu texto (leitura, escrita);
  // o FocusNode: seu foco (o cursor e o teclado do celular)
  final _field = TextEditingController();
  final _focus = FocusNode();
  // um campo do objeto State que NÃO é exibido: modificá-lo
  // não exige setState
  int _nextId = 3;

  @override
  void dispose() {
    _field.dispose();
    _focus.dispose();
    super.dispose();
  }

  void _trace(String message) {
    final t = TimeOfDay.now();
    _log.insert(0, '${t.format(context)} $message');
  }

  // chamado pelo botão E pela tecla Enter do teclado (onSubmitted)
  void _add() {
    final label = _field.text.trim();
    if (label.isEmpty) {
      return;
    }
    setState(() {
      _tasks.add(Task(_nextId++, label));
      _trace('added "$label"');
    });
    _field.clear();
    // o foco volta ao campo: a próxima tarefa pode ser digitada
    _focus.requestFocus();
  }

  void _toggle(Task task, bool done) {
    setState(() {
      task.done = done;
      _trace('"${task.label}": ${done ? 'done' : 'to do'}');
    });
  }

  void _remove(Task task, String how) {
    setState(() {
      _tasks.remove(task);
      _trace('removed "${task.label}" ($how)');
    });
  }

  // os detalhes de um toque: sua posição, relativa ao widget tocado
  void _position(TapDownDetails details) {
    final p = details.localPosition;
    setState(() => _trace('tap at (${p.dx.round()}, ${p.dy.round()})'));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Example 04 - the events')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Row(
            children: [
              Expanded(
                // CallbackShortcuts: atalhos de teclado (um teclado
                // físico: computador, emulador, tablet); Esc limpa o campo
                child: CallbackShortcuts(
                  bindings: {const SingleActivator(LogicalKeyboardKey.escape): _field.clear},
                  child: TextField(
                    controller: _field,
                    focusNode: _focus,
                    decoration: const InputDecoration(hintText: 'new task (Esc to clear)'),
                    // a tecla "Enter" do teclado do celular
                    textInputAction: TextInputAction.done,
                    onSubmitted: (_) => _add(),
                  ),
                ),
              ),
              const SizedBox(width: 8),
              FilledButton(onPressed: _add, child: const Text('Add')),
            ],
          ),
          const SizedBox(height: 12),
          for (final t in _tasks)
            // Dismissible: deslizar a linha para a esquerda a remove.
            // key: a IDENTIDADE da linha, para que o Flutter saiba qual
            // desapareceu (veja a explicação no curso)
            Dismissible(
              key: ValueKey(t.id),
              direction: DismissDirection.endToStart,
              background: Container(
                color: Colors.red.shade100,
                alignment: Alignment.centerRight,
                padding: const EdgeInsets.only(right: 16),
                child: const Icon(Icons.delete),
              ),
              onDismissed: (_) => _remove(t, 'swipe'),
              child: CheckboxListTile(
                // a caixa fica À ESQUERDA, como em uma lista de tarefas
                controlAffinity: ListTileControlAffinity.leading,
                value: t.done,
                // a caixa passa seu novo valor (bool?, daí o "!")
                onChanged: (checked) => _toggle(t, checked!),
                title: Text(
                  t.label,
                  style: t.done ? const TextStyle(decoration: TextDecoration.lineThrough, color: Colors.grey) : null,
                ),
                // uma função anônima: a tarefa DESTA linha como argumento
                secondary: IconButton(
                  icon: const Icon(Icons.delete_outline, color: Colors.red),
                  onPressed: () => _remove(t, 'button'),
                ),
              ),
            ),
          const SizedBox(height: 12),
          // GestureDetector: qualquer widget passa a ser sensível a gestos
          GestureDetector(
            onTapDown: _position,
            onDoubleTap: () => setState(() => _trace('double tap')),
            onLongPress: () => setState(() => _trace('long press')),
            child: Container(
              height: 80,
              alignment: Alignment.center,
              decoration: BoxDecoration(color: const Color(0xFFE7F5FF), borderRadius: BorderRadius.circular(8)),
              child: const Text('Touch this area (tap, double tap, long press)'),
            ),
          ),
          const SizedBox(height: 16),
          Text('Log', style: Theme.of(context).textTheme.titleSmall),
          for (final line in _log) Text(line, style: const TextStyle(fontSize: 12)),
        ],
      ),
    );
  }
}

// lib/ex06_reducer/main.dart - um formulário, um objeto, um reducer
// -------------------------------------------------------------------------
// O exemplo 05 tinha um campo de estado por campo do formulário. Para um
// formulário de verdade, preferimos UM objeto que guarda todos os valores, o
// MODELO (aqui um objeto Profile, não modificável), e descrevemos suas
// alterações em uma única função, o REDUCER:
//
//     reducer(currentState, action) -> newState
//
// O widget não modifica mais o estado: ele DESCREVE o que aconteceu, com um objeto
// ProfileAction (Edit(Field.lastName, 'Dupont'), Leave(Field.lastName)...), e
// o reducer deduz dele o novo estado. Toda a lógica fica em um só
// lugar, em uma função PURA (mesma entrada, mesma saída, sem efeito
// colateral), fácil de testar.
// O Dart se presta bem a isso: uma classe "sealed" lista todas as ações
// possíveis, e um switch sobre uma ação é verificado pelo compilador
// (um caso esquecido é um erro).
//
// O estado também guarda, para cada campo, se ele foi "tocado" (deixado pelo
// menos uma vez); a partir disso deduzimos se ele está "modificado" (seu valor difere do
// valor inicial) e se está desabilitado.
// =========================================================================

import 'dart:convert';

import 'package:flutter/material.dart';

// o nome de cada campo do formulário
enum Field { title, firstName, lastName, age, newsletter, email, country, birthDate, presentation }

// os dados do formulário: um objeto NÃO MODIFICÁVEL (todos os seus campos são
// final). Para "modificá-lo", construímos um novo (copyWith)
class Profile {
  final String title;
  final String firstName;
  final String lastName;
  final int age;
  final bool newsletter;
  final String email;
  final String country;
  final String birthDate;
  final String presentation;

  const Profile({
    required this.title,
    required this.firstName,
    required this.lastName,
    required this.age,
    required this.newsletter,
    required this.email,
    required this.country,
    required this.birthDate,
    required this.presentation,
  });

  // uma cópia, na qual alguns campos são alterados (os outros são mantidos);
  // "??": o novo valor se for fornecido, senão o antigo
  Profile copyWith({
    String? title,
    String? firstName,
    String? lastName,
    int? age,
    bool? newsletter,
    String? email,
    String? country,
    String? birthDate,
    String? presentation,
  }) {
    return Profile(
      title: title ?? this.title,
      firstName: firstName ?? this.firstName,
      lastName: lastName ?? this.lastName,
      age: age ?? this.age,
      newsletter: newsletter ?? this.newsletter,
      email: email ?? this.email,
      country: country ?? this.country,
      birthDate: birthDate ?? this.birthDate,
      presentation: presentation ?? this.presentation,
    );
  }

  // o valor de um campo, designado pelo seu nome
  Object value(Field c) => switch (c) {
    Field.title => title,
    Field.firstName => firstName,
    Field.lastName => lastName,
    Field.age => age,
    Field.newsletter => newsletter,
    Field.email => email,
    Field.country => country,
    Field.birthDate => birthDate,
    Field.presentation => presentation,
  };

  // uma cópia na qual UM campo, designado pelo seu nome, tem um novo valor
  Profile withField(Field c, Object v) => switch (c) {
    Field.title => copyWith(title: v as String),
    Field.firstName => copyWith(firstName: v as String),
    Field.lastName => copyWith(lastName: v as String),
    Field.age => copyWith(age: v as int),
    Field.newsletter => copyWith(newsletter: v as bool),
    Field.email => copyWith(email: v as String),
    Field.country => copyWith(country: v as String),
    Field.birthDate => copyWith(birthDate: v as String),
    Field.presentation => copyWith(presentation: v as String),
  };

  Map<String, Object> toJson() => {for (final c in Field.values) c.name: value(c)};
}

class ProfileState {

  final Set<Field> touched;

// as ações possíveis. "sealed": não há outras além das
// deste arquivo, o compilador sabe disso
sealed class ProfileAction {
  const ProfileAction();
}

class Edit extends ProfileAction {
  final Field field;
  final Object value;
  const Edit(this.field, this.value);
}

class Leave extends ProfileAction {
  final Field field;
  const Leave(this.field);
}

class Uppercase extends ProfileAction {
  const Uppercase();
}

class Reset extends ProfileAction {
  const Reset();
}

// o reducer: ele NUNCA modifica o estado que recebe, retorna um novo.
// O switch "desestrutura" cada ação: Edit(:final field, ...) lê
// seus campos em variáveis de mesmo nome
ProfileState reducer(ProfileState state, ProfileAction action) => switch (action) {
  Edit(:final field, :final value) => ProfileState(state.values.withField(field, value), state.touched),
  Leave(:final field) => ProfileState(state.values, {...state.touched, field}),
  Uppercase() => ProfileState(
    state.values.copyWith(firstName: state.values.firstName.toUpperCase(), lastName: state.values.lastName.toUpperCase()),
    state.touched,
  ),
  Reset() => const ProfileState(initial, {}),
};

  ProfileState _state = const ProfileState(initial, {});
  // um controller por campo de texto; um "map": Field -> controller
  final _controllers = {for (final c in textFields) c: TextEditingController(text: initial.value(c) as String)};

  @override
  void dispose() {
    for (final c in _controllers.values) {
      c.dispose();
    }
    super.dispose();
  }

  // A ÚNICA maneira de mudar o estado: descrever o que aconteceu
  void _dispatch(ProfileAction action) {
    setState(() => _state = reducer(_state, action));
    // o reducer pode ter alterado um texto (Uppercase, Reset): os
    // campos de entrada devem mostrá-lo
    for (final MapEntry(key: field, value: controller) in _controllers.entries) {
      final value = _state.values.value(field) as String;
      if (controller.text != value) {
        controller.text = value;
      }
    }
  }

  Profile get _v => _state.values;

  bool _disabled(Field c) => c == Field.email && !_v.newsletter; // o e-mail exige a newsletter

        enabled: !_disabled(field),
        maxLines: lines,
        decoration: InputDecoration(labelText: label),
        onChanged: (text) => _dispatch(Edit(field, text)),
      ),
    );

import 'package:flutter/material.dart';

enum Field { title, firstName, lastName, login, password, confirmation }

// um "record": um pequeno grupo de valores nomeados, sem precisar escrever uma classe
typedef Account = ({String title, String firstName, String lastName, String login, String password, String confirmation});

const titles = ['Mr', 'Mme', 'Melle'];
final loginFormat = RegExp(r'^[a-z0-9._-]{1,30}$');
const passwordMin = 6;

// as regras: uma função pura, que depende apenas do seu argumento.
// Ela retorna, para cada campo com erro, sua mensagem
Map<Field, String> validate(Account c) {
  final errors = <Field, String>{};
  if (!titles.contains(c.title)) errors[Field.title] = 'Choose a title from the list.';
  if (c.firstName.trim().isEmpty) {
    errors[Field.firstName] = 'The first name is required.';
  } else if (c.firstName.length > 20) {
    errors[Field.firstName] = 'The first name must not exceed 20 characters.';
  }
  if (c.lastName.trim().isEmpty) {
    errors[Field.lastName] = 'The last name is required.';
  } else if (c.lastName.length > 20) {
    errors[Field.lastName] = 'The last name must not exceed 20 characters.';
  }
  if (c.login.isEmpty) {
    errors[Field.login] = 'The login is required.';
  } else if (!loginFormat.hasMatch(c.login)) {
    errors[Field.login] = 'Unaccented lower-case letters, digits, dot, hyphen, underscore.';
  }
  if (c.password.isEmpty) {
    errors[Field.password] = 'The password is required.';
  } else if (c.password.length < passwordMin) {
    errors[Field.password] = 'At least $passwordMin characters.';
  }
  // uma regra que compara DOIS campos
  if (c.confirmation != c.password) {
    errors[Field.confirmation] = 'The confirmation does not match the password.';
  }
  return errors;
}

              obscureText: true,

              // uma regra que lê OUTRO campo
              validator: (v) => v == _password.text ? null : 'The confirmation does not match the password.',

            const SizedBox(height: 16),
            FilledButton(onPressed: _create, child: const Text('Create the account')),
            const SizedBox(height: 12),

// um horário, como descrito pela API do RdvMedecins
class Slot {
  final int startHour;
  final int startMinute;
  final int endHour;
  final int endMinute;

  const Slot(this.startHour, this.startMinute, this.endHour, this.endMinute);
}

enum Part { all, start, end }

// "8:05" em vez de "8:5"
String _time(int h, int m) => '$h:${m.toString().padLeft(2, '0')}';

// um parâmetro OPCIONAL, com seu valor padrão: [Part part = Part.all]
String timeRange(Slot c, [Part part = Part.all]) => switch (part) {
  Part.start => _time(c.startHour, c.startMinute),
  Part.end => _time(c.endHour, c.endMinute),
  Part.all => '${_time(c.startHour, c.startMinute)} - ${_time(c.endHour, c.endMinute)}',
};

// uma EXTENSION do tipo String: novos métodos para TODAS as strings
extension Formatting on String {
  // "marie pelissier" -> "Marie Pelissier"; \p{L}: uma letra, acentuada ou não
  String get capitalized => replaceAllMapped(
    RegExp(r'\p{L}+', unicode: true),
    (m) => m[0]![0].toUpperCase() + m[0]!.substring(1).toLowerCase(),
  );

  // "Marie PELISSIER" -> "MP"
  String get initials =>
      split(RegExp(r'\s+')).where((word) => word.isNotEmpty).map((word) => word[0].toUpperCase()).join();
}

// "2026-10-05" (o formato da API do RdvMedecins) -> uma data
DateTime toDate(String day) => DateTime.parse(day);
